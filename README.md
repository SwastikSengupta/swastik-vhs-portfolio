# Swastik Sengupta — VHS Portfolio

A retro VHS/CRT-inspired personal portfolio for Swastik Sengupta.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Deploy

This Vite project can be deployed to Vercel, Netlify, or GitHub Pages.

Update the project descriptions in `src/main.jsx` as your repositories evolve.
